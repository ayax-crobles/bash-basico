# Bash básico

Apuntes personales sobre Bash, shell y herramientas clásicas de Unix.

Este repositorio reúne notas practicas sobre el uso de la linea de comandos en
Linux, desde operaciones básicas con archivos y directorios hasta procesamiento
de texto, redirecciones, pipelines, procesos, permisos, expresiones regulares,
`grep`, `sed` y `awk`.

Los apuntes forman parte de mi proceso de aprendizaje y se actualizan
progresivamente a medida que incorporo nuevos conceptos y formas de trabajo.
